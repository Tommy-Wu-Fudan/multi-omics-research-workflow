# Copy-ready prompts

将方括号替换为实际绝对路径或研究信息。普通任务无需读全部资料。

## 新项目初始化

```text
请把 [本仓库路径]/templates/research-project 复制到 [新项目路径]，
保留已有文件，不覆盖同名内容。
研究问题：[人群、暴露、结局、设计]
数据与字典：[路径]
本轮交付：[任务与输出位置]
根据已提供材料填写研究合同和变量字典，未确定的字段保留未定义。
参考 [本仓库路径]/WORKFLOW.md 选择需要的 Playbook 并完成已授权部分。
```

## 在已有项目进行分析

```text
请读取 [本仓库路径]/playbooks/03-association-and-omics.md。
当前项目：[路径]
已确定的研究方案：[路径或说明]
分析脚本与字段说明：[路径]
任务：[具体分析]
输出：[路径]
先核对模型身份、样本、事件、单位和多重检验家族，
按当前合同完成预检及已批准的分析，保存完整结果与运行记录。
```

预处理改用 PB02；MR/中介改用 PB04；具体文件见 [Playbook 索引](../playbooks/README.md)。

## 核对论文与结果

```text
$research-result-trace
核对 [论文路径] 的 Results、图表说明与 [指定结果包路径]。
逐项检查数字、CI、N/事件、OR/HR、单位、模型、P/FDR 和证据强度。
输出有精确来源定位的核查台账和建议修正文句。
本轮只读核查；不改变原始结果或自行新增分析。
```

## 修订图表

```text
$research-display-revision
图表或绘图脚本：[路径]
源结果表：[路径]
修改要求：[字号、行顺序、标签、画布等]
目标格式与用途：[格式、尺寸、编辑需求]
输出：[路径]
保留统计内容、模型身份和显著性规则，交付可编辑文件与预览。
分别报告数值/语义、最终版面、可编辑对象及目标应用验证情况。
```

## 论文润色与批注处理

```text
请读取 [本仓库路径]/playbooks/06-writing-and-revision.md。
指定稿件：[路径]
批注或修改要求：[路径或说明]
结果与文献：[路径]
仅按 [授权范围] 修改，保持数值、统计口径及证据强度。
意见与当前代码/结果冲突时核查来源，不自动采纳旧审计结论。
交付修订稿、修改位置和未决项清单。
```

## 技能没有被发现时

要求助手直接读取本仓库中对应的 SKILL.md 并执行即可；读取前确认本地仓库路径。

项目安装目录使用 `<PROJECT>/.agents/skills`，个人安装目录按当前客户端配置。当前 [Codex 官方文档](https://learn.chatgpt.com/docs/build-skills)给出的个人目录为 `~/.agents/skills`；已有客户端若使用 `~/.codex/skills`，可把同一路径显式传入安装器。避免在多个被发现的位置重复安装同名技能。
