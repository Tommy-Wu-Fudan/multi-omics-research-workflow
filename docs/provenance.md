# Provenance and publication scope

本仓库源于 SCM 私有研究工作区中一次本地经验提取：先取证、再形成 Playbooks 和模板，最后选择少量流程制作并测试 Skills。公开版将项目实例改写为通用规则，删除私有证据编号、项目阈值、特定结果及机器路径。

公开版保留两项个人技能的已测试文件字节，指纹见 [skill_fingerprints.json](../validation/skill_fingerprints.json)。其独立行为测试范围见 [validation.md](validation.md)。Playbooks 是经验归纳及方法资料的链接，不能作为原项目所有分析已重现或科学有效的证明。

原项目的证据登记表、来源摘录、数据清单、运行目录、稿件、真实统计结果和测试原始日志均留在本地。这里不提供或暗示访问这些私有资料的权限。
