# PB03: association models and omics interpretation

输入：研究合同、已核查的数据、特征字典。输出：含模型身份、N/事件、效应/CI、原始 P、校正 P、失败原因和来源的完整结果；图表只是其展示层。

## 模型与估计目标

| 问题 | 方法选择与假设 | 解释及替代 |
|---|---|---|
| 基线分布 | 统计量取决于数据类型、分布及缺失 | 每个百分比有分母；不机械用基线 P 筛混杂因素 |
| 时间到首次事件 | Cox 在给定协变量下建模瞬时风险，需合理风险集/删失与 PH 假设 | HR 不等于风险比；非 PH 可考虑时间变化效应或 RMST，但需重定 estimand |
| 死亡竞争事件 | 原因别 Cox 与 Fine–Gray 分别对应不同目标 | 不能换标签当同一 HR；未运行 FG 不称分析阴性。参见 [survival 竞争风险说明](https://cran.r-project.org/web/packages/survival/vignettes/compete.pdf) |
| 二元体细胞状态与连续特征 | 若二元状态为 outcome，logistic 输出每单位特征 OR | 不写成暴露导致的蛋白变化；若要连续蛋白作 outcome，属于另一个模型 |
| 稀少病例/完全分离 | 核查案例数、参数维度、模型状态；可考虑 Firth/其他惩罚估计 | 数值收敛不能证明稳定；改变估计器需记录，不以“显著”决定回退 |
| 效应修饰/联合效应 | 事先确定乘法交互、加法交互或联合分组比较 | 分层显著性不同不等于交互显著；联合组有共同参考组；稀疏单元不可省略 |
| 预测增益 | 在独立/重采样评价中检查校准、区分度与预定时间点 | 同样本选择及评价会乐观；IPCW 与可分类子集 AUC 的检验不能互代 |

协变量依据研究问题和混杂结构选择，不将暴露后变量或机制成分自动放入调整集。性别特定模型中的恒定 sex 可以省略；其他必需字段缺失不能静默略去。每个模型族保存独立 covariate list。

## 高维筛选与解释

1. 用完整合格特征集定义检验家族：筛选模式、结局、方向/子集、方法和失败模型处理。保留全部结果及 not estimable 原因。只对选中阳性重新 FDR 会改变推断。
2. 先核对源列是否 beta、OR、HR、log(OR) 或 log2(OR)，效应单位、参考组及标准化人群。所有联合展示保留这些差异。
3. 交集条件用布尔表达式固定，并分别输出单组数、单纯交集数、方向一致后数量与完整成员。同一批参与者三次显著和同向不等于外部复制、富集超出偶然或中介机制。
4. 显著结果可能来自稀少暴露、细胞组成、检测面板、批次和所选子样本。血细胞调整等敏感性应说明其混杂/中介角色及估计目标变化，不能为了保留结果更换模型。

## 蛋白质组下游

基因映射须记录 one-to-many、无法映射与去重；保留 assay→protein→gene 对照。组织、GO/Reactome/KEGG 与 STRING 分别回答不同问题。过度代表分析的背景需与有机会被选中的测量集对应；若沿用默认全基因背景，诚实记录并分析面板选择的影响。记录数据库版本、检索日期、背景、校正方法、筛选和正/负方向集合。小集合/单基因驱动的条目应降为描述性，不能机械规定所有研究统一 n>=10。

STRING 的边表示特定网络类型下的证据关系；记录物种、阈值、证据通道、是否添加节点、physical/full 类型与聚类参数。不能由功能关联图推导直接物理相互作用、肝脏来源或因果链。[STRING 官方 FAQ](https://string-db.org/help/faq/)支持其功能关联网络的解释范围。缺参数时保留限制，不事后编造。

## 代谢组及跨组学

先区分确切代谢物、脂蛋白亚类、组成量与派生比值。只有 ID 映射和合适背景支持时才采用经典 pathway/topology；面板结构不支持时，可使用预定测量域、注释或描述性汇总，并输出绝对量敏感性和全局多重检验。高度相关及确定性比值会使“网络”主要反映测量构造。

跨组学比较限定同模式、同方向、可比较的通路或主题；精确 ID 一致与主题近似分别标记。没有匹配证据时报告不一致，不补齐漂亮的机制故事。未通过预定多重检验规则的结果应如实报告，不能因写作需要改变阈值。

## 运行与验收

先做少量真实模型预检，检查 N、事件、编码、输出尺度和警告，再运行已授权的全量。记录 runtime/包版本、代码和输入指纹、种子及每个模型状态。并行前估算内存复制成本；checkpoint 只有输入/配置/代码指纹相同时才可复用。已有测试通过后不无故增加大规模复算。
