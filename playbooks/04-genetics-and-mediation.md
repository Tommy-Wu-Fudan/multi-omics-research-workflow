# PB04: genetic evidence and mediation feasibility

适用：在已有观察性工作基础上评估 MR 或中介分解是否能回答新增问题。先给可估计性和证据边界，再执行已批准的分析；不能为形成完整故事补造中间机制。

## MR 的最小证据链

1. 明确暴露与结局的原始表型、GWAS ID、祖源、样本来源/重叠、病例对照数、基因组版本、效应单位。GWAS 文献清单或 lead-locus inventory 不等于 SNP 级 beta/SE/双等位基因摘要数据。
2. 验证冻结输入完整性并保存来源、获取日期、许可范围与校验和。缺少 SE、other allele 等必要字段时停止依赖分析，不用无来源的推算补齐。
3. 记录工具强度和 LD 规则、参考人群、覆盖率及移除原因。阈值应根据当前研究、工具可用性和参考人群预先确定。无工具的亚型标 not estimable，不能换整体暴露的 SNP 或放宽阈值来凑数。
4. 对齐 effect allele、build 和方向；处理回文/多等位/重复以及频率不明的变异，保留逐 SNP 决策。位置接近不代表同一 SNP；proxy 需预设规则和明确记录。[TwoSampleMR 官方 harmonisation](https://mrcieu.github.io/TwoSampleMR/articles/harmonise.html)说明效应必须对齐至同一等位基因。
5. 根据可用工具和假设选择估计器及敏感性。一个 SNP 的 Wald ratio 无法提供多工具异质性/横向多效性排查；更多方法一致也不证明排除限制成立。记录 not applicable、not run、failed 与 not estimable，不能全部填空。
6. 二元暴露的 log odds 与线性混合模型 beta 不同。仅在输入确为 log odds 时才可讨论按 genetically predicted odds doubling 换算，并记录转换公式、尺度及解释。不能把未经确认的 raw beta 当作 log odds。
7. 预先定义主/次结局和检验家族；结果要并列给 nominal 与 multiplicity-adjusted 结论。阴性结果不等于证明零效应，反向点估计不自动称保护作用。

## MR 假设与替代方案

工具相关性、与混杂独立及排除限制都需论证；祖源差异、样本重叠、选择、横向多效性与相关代谢性状会影响估计。独立结局 GWAS 减少重叠但可能不复现本研究结局。cis-only、共定位、双向分析或排除生物学位点可回答不同问题，但会减少工具/效能或需要额外输入，不能自动扩大研究路线。共定位是共享位点证据，不是代谢物中介的证明。


## 中介和联合分解

先画出测量时间顺序并定义 direct/indirect/total effect 的尺度及人群。暴露/中介/结局混杂、暴露诱导的中介-结局混杂、positivity、一致性及正确模型设定等假设必须与设计相容。同基线测量及同队列挑选候选分子会使估计偏向探索。

检查每组样本和事件，尤其稀少驱动基因。相同样本、编码、协变量设计矩阵、时间单位和估计尺度才允许双实现对照。R 的事件 1/删失 0 与特定 SAS 宏的反向 status 约定只在各自接口内成立，不能跨接口复制。

bootstrap 是不确定性估计方式，不修复因果识别。保存种子、成功/失败重复数、CI 方法与 MC 稳定性；不要为产生好看的 CI 改核心统计结果。PM 依赖 total effect 和分解尺度；总效应接近零、方向不一致或 PM 越界时不强行显示百分比，也不能对多个单中介 PM 求和。

模块/PCA 联合中介、多个相关分子同时入模和逐个单中介是不同目标；联合表示降维可减少共线性，但改变分子解释。任何新路线先提交具体可审阅方案。

验收：每条估计有来源及尺度，不能估计的组合有理由，结果和不确定性可回溯，敏感性不掩盖主分析；科学解释不超过这些证据。
