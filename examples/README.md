# Synthetic result-trace exercise

[result-trace/input](result-trace/input/) 中全部内容为虚拟研究资料，没有真实受试者或真实研究结果。保留误导性文件名、错误论断及正确对照，用来测试版本识别和证据边界。

```text
$research-result-trace
请使用 [本仓库路径]/examples/result-trace/input 下的资料，
核对 claims.md 中每条论断，并遵循 source_manifest.json 指定的版本。
本轮只读，输出到 [新的测试输出目录]。
输出包含来源定位、判断、支持内容、问题及建议修正。
```

评价者在独立执行结束后再阅读 [验收协议](../tests/skill_acceptance.md)。不要向执行者预先提供预期答案，也不要将虚拟结果写入真实论文。
